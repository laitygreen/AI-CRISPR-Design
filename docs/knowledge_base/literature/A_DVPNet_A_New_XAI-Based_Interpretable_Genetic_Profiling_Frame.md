## 1. 一句话核心
提出 DVPNet——把 Vision Transformer+概率电路（VPNet）中的图像编码器替换为 Nucleotide Transformer（NT），用"每细胞随机抽 900 个表达基因 → TSS 锚定序列 → NT 冻结嵌入 → 概率电路分类"的可解释流程，对"癌细胞 vs 正常细胞"分类，并从可计算的类条件概率中提取每个基因的概率贡献分数 S(gene)，得到超越单纯表达统计（共表达网络/WGCNA）的基因与通路画像。

## 2. 方法要点（详细）
- **底座 VPNet**：可处理多模态/多编码器/多类别的可解释分类器；对每个信息单元维护类条件密度 P(z|class)，用乘积节点保证可分解性（decomposability：各输入 scope 不相交）、用相同 scope 的求和节点子节点保证平滑性（smoothness），从而整体保持可计算（tractable）。
- **基因向量编码（NT 冻结嵌入）**：① 每细胞随机抽取 900 个不重名的表达基因（固定随机种子，不按表达量筛选，低表达基因同等对待）；② 依据 GTF 参考注释取每个基因 TSS 上游 −2000 bp 至下游 +500 bp 的核苷酸序列；③ 输入 Nucleotide Transformer v2（InstaDeep/NVIDIA，500M 参数，预训练于 3,202 个人类基因组 + 850 物种基因组）；④ 取倒数第二层所有 token 向量，对每个标量分量做平均池化 → 1024 维"基因向量"；⑤ NT 参数全程冻结，保证 scope 不变性。
- **概率电路结构**：#circuits = 模态数 × 编码器数 × 类别数 = 1×1×2 = 2 个电路；每个标量分量 gi,k 对应一个叶节点，编码单变量高斯 N(gi,k; μi,k, σ²i,k)；类条件概率 P(sample|class) = ∏ᵢ₌₁⁹⁰⁰ P(Gi|class)；类先验 π 由小神经网络参数化（Bernoulli）；贝叶斯后验 P(y=c|sample)。
- **损失与训练**：交叉熵 + λ×Shannon 熵正则（负熵项，λ≥0）；逐样本优化；输入向量做样本内标准化 Ẽ=(G−μ)/σ（样本间隐式数据增强）；log 空间实现。电路超参：depth=2、latents=16、repetitions=2、pieces=2；batch size=20；Adam 优化器。
- **贡献分数定义**：S(gene|class) = (1/k)Σ log P(Gi|class)（k 为该基因在样本中出现次数）；S(gene) = S(gene|cancer) − S(gene|normal)，正分偏癌细胞贡献、负分偏正常细胞贡献；样本级 S(gene|sample) = log P(Gi|cancer,sample) − log P(Gi|normal,sample) 捕获基因功能的样本依赖性。
- **统计过滤**：只保留"计数–分数矛盾对"（S>0 但 count_cancer<count_normal，或 S<0 但 count_cancer>count_normal），以抑制基因出现频率对贡献分数的干扰——9,540 个观测基因中筛出 1,524 个。
- **数据集**：GSE131907 单细胞肺癌图谱（208,506 细胞、44 例患者，含原发/胸水/淋巴结/脑转移及正常组织）；仅取原发灶上皮细胞 tLung（癌）与 nLung（正常）构建二分类；train/val/test = 3,420/570/570（每类），固定随机种子。
- **下游分析**：用样本级 S(gene|sample) 替代表达量构建 WGCNA（软阈值按无标度拓扑自动选择，TOM + 层次聚类 + 动态树切割，最小模块 2）→ 50 个模块 1,812 基因，按模块内连通度定 hub 基因，逐模块 GO 富集；另对 9,540 基因整体做 GO 富集（q<0.05 得 4,000 项），按通路内基因平均 S 排序。

## 3. 关键结果与指标
- **分类性能**：训练集 AUROC 0.992 / AUPRC 0.994 / Acc 0.974 / F1 0.974；测试集 AUROC 0.975 / AUPRC 0.981 / Acc 0.940 / F1 0.939——无明显欠拟合/过拟合。
- **超越统计的证据**：基因出现频率差与 S(gene) 之间 Pearson r = 0.356、Spearman ρ = 0.408（中度相关），说明贡献分数同时融合了统计信号与 NT 嵌入的生物特征；1,524 个"矛盾对"基因中排名靠前的包括 TSPAN32（count_cancer 6 / count_normal 11，S=290.894）、TPSD1（280.12）、ANKRD2（188.40）；文献已知癌症相关基因 ITGA5、SIGLEC9、NOTUM、TP73、SFRP5、NLRC3、CD300A/C、PITPNM3、SEMA6B 均出现在前列，支持生物有效性。
- **模块画像**：50 个 WGCNA 模块（11–301 基因/模块），S(genes) 最高 orange 模块 45.71（hub：KRT83、TDRD1、IGKV1-12），最低 royalblue 模块 −43.90；0074ff 模块癌/正常样本间 S 差最大（38.62）。
- **通路层面**：Smean 最高的 GO 集中于免疫球蛋白复合物、经典补体激活（GO:0006958，25/39 基因）、抗体依赖细胞毒、体液免疫——提示模型实际区分的是肿瘤微环境免疫应答差异（作者在 Limitations 中承认）。
- **可解释性产出**：每个基因/通路/模块的可视化贡献分数、样本级贡献网络，均可导出做下游生物学分析。

## 5. 对我们项目的可借鉴点（重点，结合大肠杆菌氨基酸细胞工厂 + AI-CRISPR 设计）
1. **"冻结 DNA 基础模型嵌入 + 概率电路"的可解释分类范式（B3/M3）**：可直接照搬到"高产 vs 低产大肠杆菌菌株/菌落分类"——用 DNABERT-2/NT 生成代谢通路基因（TSS ± 2.5 kb）的冻结嵌入，接概率电路做类别判定，输出每个基因对高产表型的概率贡献分，作为 AI-CRISPR 系统靶基因选择的解释性依据（回答"为什么打这个基因"）。
2. **随机抽样子集 + 贡献分数去统计化（M1 特征工程）**：其"随机抽 900 基因 + 矛盾对过滤"迫使模型学习组合信号而非类间出现频率差——我们筛选 gRNA 靶点（如 β-丙氨酸/L-高丝氨酸通路与非通路基因）时，可用同类策略避免模型只依赖基因表达丰度，突出序列编码的功能信号；固定随机种子保证可复现。
3. **样本级贡献分数构建"功能网络"替代共表达网络（B2）**：用 S(gene|sample) 而非 RNA 表达量跑 WGCNA + hub 基因分析，可发现表达相关但功能贡献不同的基因模块——对代谢工程可用于发现与产物合成耦合的调控 hub（转录因子/转运蛋白），为多基因编辑（CRISPR 组合打靶）提供依据；其逐模块 GO 富集流程可直接用于 KEGG/GO 通路注释。
4. **TSS 锚定序列编码方案（B2 特征设计）**："−2000 bp 上游 + 500 bp 下游 + 平均池化倒数第二层"是给基因级任务做序列嵌入的现成配方，避免直接编码 mRNA 丢失内含子/启动子调控信息——大肠杆菌（无内含子、操纵子结构）可简化为"启动子+UTR+ORF 起始区"的固定窗口，用于启动子强度/翻译效率预测的输入特征。
5. **类条件密度贡献分解（XAI 方法学）**：高斯叶节点 + 可分解乘积结构的"逐标量分量贡献"机制，比 SHAP/注意力权重的解释更严格（概率语义明确）；若我们做 gRNA 效率模型的解释模块（M3/XAI），可借鉴其"每个输入单元一个可计算的类条件分布"设计，输出"该 gRNA 特征支持/反对高效编辑"的概率贡献。
6. **与氨基酸代谢的巧合关联**：该文 royalblue 模块（最低 S）的 GO 富集含 "L-methionine catabolic process" 与 "methionine adenosyltransferase complex"——与我们的 L-高丝氨酸/蛋氨酸代谢路径直接相关，可作为"通路级贡献打分用于代谢靶点筛选"的文献佐证（尽管对象是人体细胞）。

## 6. 与我们方案的冲突/差异点
- 对象差异：该文处理人类单细胞 RNA-seq（每细胞 900 基因、细胞异质性），而我们的对象是大肠杆菌菌株/培养条件（基因数少、无细胞异质性），"随机抽 900 基因"的规模需大幅缩水；其类别（癌/正常）是天然二分类，而高产/低产菌株边界模糊，需定义稳健的表型标签。
- 分类信号来源：其 top 通路（免疫/补体）实际反映组织微环境差异而非癌细胞内在机制（作者自认 Limitations）——提示"可解释分数"可能学到混淆变量；我们在菌株分类中必须严格控制培养条件、批次、菌株背景等混杂因素，否则贡献分数会指向混淆变量而非代谢机制。
- 未做湿实验验证：其基因排序只有文献佐证，没有功能实验闭环；我们项目有条件（大肠杆菌工程菌 + CRISPR 验证）把"预测的高贡献靶基因"直接做敲除/过表达验证，形成"预测→编辑→表型验证"闭环，这比该文更进一步。
- 计算成本：NT-500M 逐基因前向 + 概率电路，在人类基因规模可行，但若对大肠杆菌全基因组（~4,400 基因 × 菌株）批量做需注意成本；可改用更小的 DNABERT-2（117M）或 HyenaDNA。

- 写 README：记录"贡献分数 ≠ 表达差异"的结论（r≈0.36），说明 XAI 输出需与统计方法交叉验证。
