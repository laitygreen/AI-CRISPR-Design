## 1. 一句话核心
提出 Generanno——500M 参数的"紧凑型"原核基因组基础模型（transformer encoder、单核苷酸 token、8192 bp 上下文、715 Gbp 功能序列预训练），在基因适应度/抗生素抗性/基因分类/分类学等 Prokaryotic Gener Tasks 上全面超越 8 倍参数量的 GenomeOcean-4B，并在宏基因组基因注释上达到 SOTA（优于 GLIMMER3/GeneMarkS2/Prodigal/GeneLM），首创基于纯序列的假基因预测。

## 2. 方法要点（详细）
- **架构**："Llama for MLM"——把 Llama 结构改造为双向注意力（MLM 范式）的 transformer encoder；26 层、hidden size 1280、intermediate 3520、vocab 64、16 个注意力头（4 个 KV 头）、上下文长度 8192 bp、RoPE 位置编码、SiLU 激活；全层全局注意力（对比 ModernBERT 的局部+全局混合，Generanno 为最大化基因组任务性能全用全局）。
- **预训练数据（functional sequence training）**：从 RefSeq 全部原核生物基因组中只提取**功能性序列**（编码基因、各类 RNA、启动子/增强子等调控区），共 715 Gbp。核心理由：DNA 本质接近随机序列，功能区是"随机打字中偶然打出的句子"，非功能（junk）DNA 变异率高、不提供有效信息且是噪声；该策略源自其前作 Generator，后被 Evo2 印证。
- **Tokenization**：单核苷酸 token（A/T/C/G 各为 1 token），不用 k-mer/BPE——保留单核苷酸分辨率以精确定界 CDS 起止；对比 SegmentNT（NT）与 GeneLM（DNABERT）用 6-mer tokenizer 需额外拆 token 定界、累积误差。
- **预训练**：batch size 2M tokens、AdamW、cosine 学习率+warmup、共 2 epochs、1.4 万亿 tokens、Flash Attention、ZeRO。
- **Prokaryotic Gener Tasks 基准（新构建）**：① 基因适应度预测（Fitness Browser 数据，覆盖 pH/温度/碳源/氮源/化合物条件）；② 抗生素抗性预测（CARD 正样本 + RefSeq 随机采样负样本，长度分布匹配控制混杂）；③ 基因分类（CDS/假基因/tRNA/rRNA/ncRNA/基因间区，平衡采样，难点是 CDS vs 假基因）；④ 分类学分类（GTDB，预测门到科，排除 domain 与 genus/species；3 个子任务：SSU 16S 标记、混合标记基因、随机片段分类）。
- **宏基因组注释微调**：视为 token 分类——RefSeq 注释生成等长标签（非编码=0；编码=±1 按链），+1/−1 连续段即 CDS；随机采样 5% 基因组**片段**（片段级而非基因组级）训练，保证跨物种 few-shot 泛化并防记忆过拟合。
- **评估**：10 折交叉验证；超参搜索 lr∈{1e-5,2e-5,5e-5,1e-4,2e-4,5e-4}×batch{64,128,256,512}；6 项注释指标（bp 精度、bp 灵敏度、起始/终止/边界/整段匹配准确率）；33 个原核物种（33 基因组+16 质粒）in-sample 评测 + 31 古菌物种（42 序列）zero-shot 泛化测试。

## 3. 关键结果与指标
- **Prokaryotic Gener Tasks（10 折 CV）**：基因适应度 minimal glucose 0.875、L-Histidine 0.872、L-Arabinose 0.770、LB 20°C 0.638、Cisplatin 0.602；抗生素抗性 0.972；细菌基因分类 0.981；SSU 分类 0.972；混合标记 0.860；随机片段分类 0.941——除个别适应度子任务外全面最优，且 500M 模型超越 GenomeOcean-4B（8 倍参数）。
- **基因分类细类准确率**：假基因 pseudo 0.962（DNABERT-2 仅 0.627、NT-v2 0.957、GenomeOcean-4B 0.946）、rRNA 1.000、CDS 0.947、tRNA 0.998、ncRNA 0.998、基因间区 0.981。
- **随机片段分类学**：门 0.958 / 纲 0.952 / 目 0.918 / 科 0.925——无需标记基因/组装即可直接分类任意 DNA 片段。
- **细菌基因组注释（in-sample）**：起始 0.933 / 终止 0.933 / 边界 0.882 / 整段匹配 0.879 / bp 精度 0.910 / bp 灵敏度 0.998（对比 Prodigal 0.910/0.910/0.845/0.837/0.909/0.992；GLIMMER3 0.875/0.874/0.784/0.773/0.904/0.986；GeneLM 灵敏度仅 0.943）。
- **质粒注释（in-sample）**：起始 0.887 / 终止 0.892 / 边界 0.810 / 整段 0.803 / 灵敏度 0.994（Prodigal 整段 0.730）。
- **古菌 zero-shot（31 物种，基因组序列）**：起始 0.853 / 终止 0.849 / 边界 0.753 / 整段 0.747 / bp 精度 0.858 / bp 灵敏度 0.990——与 HMM 方法 in-sample 水平相当、显著优于 GeneLM（整段 0.532、灵敏度 0.821），证明对未见过物种的泛化力。
- **假基因预测**：Generanno 0.962，首创纯序列假基因识别（无需比较基因组学/功能实验）。
- 局限：无法区分重叠基因（预测为连续区间，需后处理）；未覆盖真核注释。

## 5. 对我们项目的可借鉴点（重点，结合大肠杆菌氨基酸细胞工厂 + AI-CRISPR 设计）
1. **"紧凑模型 > 超大模型"选型依据（M3）**：500M 打败 4B（8 倍参数）的机制——功能序列训练 + 单核苷酸 token + 双向注意力 + 恰当上下文；并引 ProteinGym 证据（科学域模型 500M–10B 达峰、之后平台期甚至退化）。这直接支持我们 M3 在 E. coli 任务上优先选 100M–1B 级底座而非盲目堆参数。
2. **功能序列训练策略（M3 数据管线）**：只预训练 RefSeq/EcoCyc/RegulonDB 注释的功能区（CDS、RNA、启动子等），剔除"垃圾 DNA"——可直接指导我们 E. coli 语言模型预训练语料的构建，提升数据信噪比。
3. **单核苷酸 token + 长上下文（8192 bp）的精细任务价值**：若我们做翻译起始位点/启动子强度/假基因等碱基级任务，应避免 6-mer tokenization 的定界误差累积——为 M1/M3 的序列编码选型提供依据。
4. **片段级采样微调（防记忆）**：随机 5% 片段而非整基因组微调，实现跨菌株 few-shot 泛化——适用于我们基于多菌株 E. coli 库构建泛化模型，防止模型记住特定菌株。
5. **基因适应度预测任务与我们高度同构**：Fitness Browser 的"环境条件（pH/温度/碳源/氮源/化合物）×基因→适应度"正是我们"环境×基因型→氨基酸产量/生长"预测的模板——可作为 M4 细胞工厂表型预测的预训练/评测任务，甚至用其微调权重迁移。
6. **6 指标注释评估协议（B3）**：bp 精度/灵敏度 + 起始/终止/边界/整段匹配 6 项指标，可用于我们菌株基因组重建与编辑结果验证的自动评估。
7. **Gener Project 的"手写 MoE"理念**：按进化域（真核/原核/病毒）与任务（设计 >8k / 注释 <8k）划分专家模型——启发我们系统按"序列设计（gRNA/蛋白）+ 序列分析（注释/分类）"分模块部署不同模型。

## 6. 与我们方案的冲突/差异点
- 预印本未经同行评审，性能数字需谨慎引用；且任务聚焦"注释/分类"，不直接解决 gRNA 效率/脱靶预测，需把嵌入/微调框架迁移到回归/打分任务。
- 单核苷酸 token + 8192 bp 上下文的 transformer 推理成本高（二次注意力），与我们轻量部署/快速迭代的需求有张力（作者也承认计算开销是其后续优化点）。
- "紧凑模型即可"的结论与部分团队"更大 LLM 更强"的直觉冲突——方案评审时需以任务实测为准。
- 重叠基因处理缺陷：E. coli 基因组存在重叠 ORF（如某些操纵子/双顺反子区），直接使用其注释结果需后处理。
- 其分类学任务排除 genus/species 级（样本量限制），而我们菌株级鉴别（strain-level）恰是代谢工程常需的粒度。
