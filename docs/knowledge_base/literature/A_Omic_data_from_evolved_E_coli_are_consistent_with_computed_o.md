# 文献卡：Omic data from evolved E. coli are consistent with computed optimal growth from genome-scale models（进化大肠杆菌的多组学数据与基因组规模模型计算的最优生长一致）

## 1. 一句话核心
对三组适应进化（连续传代 700–1000 代）的 E. coli（甘油、乳酸、Δpgi 葡萄糖三种 M9 最小培养基）获得 50 套定量蛋白质组与转录组数据，用"简约酶用量 FBA（pFBA）"将代谢基因分为 5 类，发现 **≥98% 的 FBA 最优生长解的活性反应有组学数据支持**，进化菌株上调最优生长通路基因、下调非功能通路基因、克服必需基因剂量瓶颈并抑制严谨应答——证明组学数据与 GEM 计算的最优生长状态高度一致。

## 2. 方法要点（详细）
- **适应性进化实验**：M9 最小培养基（乳酸/甘油/Δpgi-葡萄糖）中连续传代 700（甘油）、800（Δpgi）、1000（乳酸）代，直至生长速率稳定（至少 5 天维持最大速率）；每条件 3–6 个平行；进化后生长速率与底物得率均提升。
- **数据规模**：50 套定量蛋白质组，983 个高置信蛋白（其中 731 个在所有菌株中均鉴定到）；转录组为已发表的微阵列数据（Fong et al., 2005），GCRMA 重归一化，低于阴性对照表达水平（FDR=0.05）的基因剔除。
- **pFBA（Parsimonious enzyme usage FBA）**：基于 E. coli K-12 GEM（Feist et al., 2007, iAF1260，1260 ORF）的双层线性规划：先用实测底物摄取速率做 FBA 求最大生长速率，再在保持最优生长的前提下最小化所有基因关联反应的通量绝对值之和（总酶用量代理）。6 步流程：①FBA 测基因必需性 → ②无生物量约束 FVA 找零通量反应 → ③FBA 求最优生长速率并设为生物量下界 → ④再次 FVA 找代谢低效反应 → ⑤LP 最小化总通量并设为上界 → ⑥固定最优生长+最小通量下 FVA 找交替最优解。
- **5 类基因**：essential（必需）、pFBA optima（最优解内、贡献最大生长与最小通量）、ELE（酶学低效：需更多酶步骤达到相同目的）、MLE（代谢低效：使用会降低生长速率）、pFBA no-flux（该条件下无法承载通量）。
- **统计方法**：超几何检验（pFBA 各类在上调/下调基因蛋白中的富集/缺失，见表 I）；10000 次随机置换检验（各类内上调/下调 fold-change 总和 vs 随机差异表达基因集合）；单侧 Wilcoxon 检验（各类表达水平排序）；RegulonDB 6.0 调控子富集（超几何 + FDR=0.1）；SVD（GO 类共变分析）；PathWave（代谢网络差异表达通路发现）。
- **蛋白质组学流程**：Barocycler 压力循环裂解 → 胰酶消化（1:50）→ SCX 25 级分 → LTQ 离子阱 MS/MS → SEQUEST 鉴定（XCorr≥2、discriminant score≥0.6、peptide prophet≥0.99，共 44610 个肽段）→ AMT tag（准确质量-洗脱时间标签）定量 → DAnTE 软件（log2 转换、线性回归归一化、Rrollup 蛋白汇总、Grubbs 检验 P=0.05 剔除离群肽段）。

## 3. 关键结果与指标
- **覆盖率**：99%（essential 类）与 98%（pFBA optima 类）的活性反应被转录组+蛋白质组联合支持；非必需活性基因关联反应的联合覆盖率达 **97.7%**（未支持的多为 H₂O/NH₄⁺ 转运与辅因子合成反应）。
- **缺失蛋白归因**：essential 与 pFBA optima 类缺失蛋白中约 40% 属于 GO 类"membrane/integral to membrane/transport"（膜蛋白系统性缺失）；45% 的缺失蛋白在同类的同工酶可替代。
- **表达水平排序**：Essential > pFBA optima > ELE > MLE > pFBA no-flux，多数两两比较显著（单侧 Wilcoxon，P 最低至 1.98E-39）。
- **进化过程中的差异表达**：pFBA optima 基因在转录组/蛋白质组中显著上调（超几何 P 低至 4.01E-11）；MLE 不上调（多数数据集下调）；pFBA no-flux 显著下调（转录组 P=8.3E-8，蛋白 P<1E-16）；必需基因上调以克服**剂量瓶颈**（下调的必需蛋白在 WT 中本已高丰度）。
- **调控子富集**：下调与已知调控子一致（甘油：FlhC/FlhD、GatR、Hns；乳酸：Crp、DgsA；Δpgi：Crp、IhfA/IhfB、MetJ、ArcA）；**上调侧几乎无已知调控子富集**（仅甘油微阵列富集 ArgR、LysR、MetJ、PurR、Fis），提示未知/突变型调控机制（RNAP、Crp、Hfq、AtoS 突变）。
- **严谨应答**：170 个严谨应答差异表达基因中 97 个在进化菌株中共差异表达，**>90% 方向相反**（进化菌株抑制严谨应答，但 ilvM、ilvD、thrL、folE 等氨基酸合成基因仍上调）。

## 5. 对我们项目的可借鉴点（重点）
1. **pFBA 基因分类法可直接迁移到菌株设计**：用现代 E. coli GEM（如 iML1515 + COBRApy）对我们 β-丙氨酸/L-高丝氨酸改造株做 essential/optima/ELE/MLE/no-flux 分类，即可计算得到"应增强（optima）/应敲低（MLE、no-flux）"的基因清单——这正是我们 AI-CRISPR 靶点选择（M1/M3）的计算输入，比单纯生物学先验更系统。
2. **组学-模型一致性检验框架**：本项目 B2 多组学管线可输出"FBA 通量预测 vs 转录组/蛋白组表达"的一致性报告（覆盖率、方向一致性、富集检验），作为菌株改造效果评估与模型校验的标准化流程。
3. **调控子富集分析流程（RegulonDB + 超几何/FDR）** 可直接复用于我们自己的转录组数据，识别改造株中全局调控变化（Crp、ArcA、MetJ、Fis 等），辅助解释"为什么基因操作有效/无效"，并为 LLM-Agent 提供机理级解释素材。
4. **"上调基因没有已知调控子富集"的发现**：提示存在未知/突变型调控机制（RNAP、Crp、Hfq、AtoS 突变）——这正是 LLM/知识图谱可介入的开放问题：让大模型从文献/序列中挖掘突变调控因子与表达变化的关联。
5. **严谨应答（ppGpp）抑制现象**：氨基酸合成基因的表达受严谨应答影响，菌株设计（尤其氨基酸高产）时应把 ppGpp/严谨应答相关基因（如 relA/spoT）纳入 CRISPRi 敲低候选，可借鉴本文"与严谨应答基因集（170 个）取交集"的分析思路。
6. **数据集可复用**：50 套定量蛋白质组 + 转录组是高质量 E. coli 组学语料，可作为菌株设计 ML 模型（基因表达→表型）的补充训练/验证数据。

## 6. 与我们方案的冲突/差异点
- 研究对象是"生长速率最优"而非"目标产物最优"：pFBA 目标函数需改为产物耦合生长（growth-coupled production，如 OptKnock/产物下界约束）才能直接服务产物设计，需二次开发。
- 使用的是 2010 年 iAF1260 模型与微阵列数据；分辨率与覆盖度低于现代 RNA-seq/iML1515，复现时需更新模型与数据。
- 该文不含 AI/CRISPR 内容，属于约束建模+组学验证，与我们的 AI-CRISPR 部分是互补关系。
