# 知识库 · 模块 03：基因型-表型大模型（M3）

> 对应项目流程：给定目标产物 → LLM 推荐靶点组合与编辑策略（生成式设计）

## 1. 项目流程步骤
1. 构建指令数据集：产物→靶点/通路问答对（来源：文献+专家标注+GEM 分析）
2. 底座选择：BioGPT / BioT5 / 通用 LLM（Qwen/Llama）+ RAG
3. LoRA 微调领域知识（代谢通路、CRISPR 设计规范）
4. RAG 增强：检索文献/数据库（EcoCyc、iML1515 结果）作为上下文
5. 评估：推荐命中率（湿实验验证）、消融实验、人工评估
6. 输出：靶点推荐清单（含理由与证据链）

## 2. 文献支撑
| 文献 | 分级 | 支撑点 | PDF 已下载 |
|---|---|---|---|

| LLM for GEM interpretation (2026) | S | LLM 解析基因组规模代谢模型 | ⚠️ 需手动 |

## 3. 生信方法指导
- 指令数据构建：模板化生成 + 人工审核（质量 > 数量，1000 条高质量优先）
- 知识检索：EcoCyc API / iML1515 通量结果 / 已读文献摘要 → 向量库（embedding）
- RAG 管线：HuggingFace sentence-transformers + FAISS 或 Chroma
- 提示工程：few-shot 示例（β-丙氨酸/高丝氨酸案例）+ 输出约束（JSON schema）
- 评测集：30-50 个真实靶点问题，专家打分（正确性/可执行性/新颖性）

## 4. 大模型训练建议
- LoRA 微调：rank=8-16，学习率 1e-4 量级，训练 1-3 epoch（防遗忘）
- 微调语料三类型：CRISPR 设计问答、代谢通路知识、脱靶/效率评估理由
- 显存不足时：退化为 通用 LLM API + RAG（仍是"大模型应用"，注意在文中区分）
- 与统计模型协同：LLM 候选 → M1/M2 打分过滤 → 最终推荐（混合架构）
- 防幻觉：答案必须附引用来源；无法确定时明确说"不确定"

# 知识库 · 模块 04：靶点设计 Agent（M4）

> 对应项目流程：端到端工作流（产物 → 靶点 → gRNA → 评分 → 实验方案）

## 1. 项目流程步骤
1. 定义 Agent 工具集：B1 扫描、M1 效率、M2 脱靶、GEM 查询、文献检索
2. 编排逻辑：LLM 规划 → 调用工具 → 汇总结果 → 输出设计清单
3. 规则引擎兜底：PAM 合法性、必需基因保护、编辑窗口校验
4. 交互界面：Notebook/Web 演示（评审展示用）
5. 评测：端到端 5-10 个设计任务的完成率与命中率

## 2. 文献支撑
| 文献 | 分级 | 支撑点 |
|---|---|---|
| CRISPR-GPT (2024) | S | LLM Agent 编排参考（多工具调用范式） |
| LLM for Metabolic Engineering (2024) | S | 代谢工程 Agent 工作流 |
| CRISPR computational survey (2022) | A | 计算工具集成全景 |

## 3. 生信方法指导
- 工具封装：每个模块暴露统一函数接口（输入/输出 JSON schema）
- 编排框架：LangGraph / 自研状态机（工具调用循环+错误重试）
- 日志：记录每步输入输出（可解释性、评审需要）
- 演示：Streamlit 或 Notebook 一键生成设计报告

## 4. 大模型训练建议
- LLM 用函数调用（function calling）能力（Qwen/Llama 均支持）
- 无需微调 M4：Prompt 编排 + 工具定义即可，重点是评测反馈
- 评测指标：任务完成率、工具调用正确率、最终设计被湿实验采纳率
- 迭代：把 Agent 失败案例加入 prompt 示例（self-refine）

# 知识库 · 模块 08：湿实验验证闭环（D）

> 对应项目流程：AI 设计 → 湿实验 → 数据回流 → 模型迭代（竞赛"真验证"核心）

## 1. 项目流程步骤
1. E1 gRNA 效率回构：3 基因 × 5 gRNA（覆盖预测高/中/低），CRISPR 编辑+测序
2. E2 靶点组合改造：按 M3 推荐改造（panD/aspC 强化、竞争基因敲除、NADPH 再生）
3. E3 动态调控（可选）：Lsr 群体感应元件验证（对接课题 3）
4. E4 数据回流：实测编辑效率/滴度 → 加入训练集 → 第 2 轮模型迭代
5. 记录：实验记录本（总决赛备查）+ 原始数据归档

## 2. 文献支撑
| 文献 | 分级 | 支撑点 |
|---|---|---|
| E. coli β-alanine biosensor (2022) | S | 生物传感器辅助筛选策略 |
| L-Homoserine strategies review (2024) | S | 高丝氨酸改造路径对照 |
| E. coli W3110 homoserine (2022) | S | 高丝氨酸工程实例 |
| PEP-OAA-Pyruvate review (2024) | S | 前体供给节点改造 |

## 3. 生信方法指导
- 编辑验证：Sanger 测序 / amplicon-seq 计算编辑效率（CRISPResso2 或自写）
- 脱靶验证：简化 WGS 或靶向扩增测序比对（GUIDE-seq 思路）
- 发酵：摇瓶梯度 + 5L 罐（如有），记录滴度/得率/生长
- 数据回流：编辑效率/滴度按《文献检索阅读规则》数据字典入库

## 4. 大模型训练建议
- 主动学习：优先实验验证模型不确定度高的位点（信息增益最大）
- 迁移学习：用公开数据预训练 → 自产数据微调（小样本高效）
- 闭环迭代：每轮实验后重训模型，报告指标提升曲线（评审亮点）
- 小样本技巧：数据增强 + 正则化 + 集成平均，防止过拟合
