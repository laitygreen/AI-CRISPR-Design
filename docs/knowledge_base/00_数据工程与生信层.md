# 知识库 · 模块 00：数据工程（M0）

> 对应项目流程：数据采集 → 标准化 → 版本管理 → 训练/评测划分

## 1. 项目流程步骤
1. 采集：自产湿实验数据（gRNA/编辑/脱靶/表型）+ 公开数据集
2. 标准化：统一字段命名、单位、元数据（source/experiment_id/lab_notes_ref）
3. 清洗：去重、缺失标记、负样本定义（测序确认 vs 平板筛选）
4. 划分：按基因/宿主/批次划分训练-验证-测试（防同源泄漏）
5. 版本管理：DVC 或 git-lfs，锁定数据版本与代码版本

## 2. 文献支撑
| 文献 | 分级 | 支撑点 |
|---|---|---|
| DeepCRISPR (Chuai 2018) | S | gRNA 数据集构建与去偏方法（负样本构造策略） |
| CRISPRon/CRISPRoff (Xiang 2021) | S | 大规模 gRNA 效率数据整合流程（多来源合并清洗） |
| Doench 2016 (Azimuth) | S | 标准数据集与评估协议（train/test 划分规范） |
| GUIDE-seq / CIRCLE-seq | S | 脱靶实测数据采集标准（M2 标签来源） |

## 3. 生信方法指导
- 工具：Python pandas/polars；DVC；Biopython（SeqIO 处理序列）；pysam（BAM/VCF）
- 数据字典：见《文献检索阅读规则_v1.md》2.1 节五类字段
- 负样本策略："未编辑成功"需有测序证据；同一宿主背景分组
- 去偏：不同实验室数据按批次建模或加 batch 特征（参考 DeepCRISPR 的去偏方法）

## 4. 大模型训练建议
- 数据增强：gRNA 序列 ±PAM 扰动、反向互补扩增
- 类别平衡：编辑效率分档（高/中/低）重采样或加权损失
- 预训练数据：可先在大肠杆菌全基因组无监督预训练（掩码语言模型），再下游微调
- 评测协议：按基因划分留出集，报告 Pearson r + AUROC + top-k 命中率

# 知识库 · 模块 05：CRISPR 位点全基因组扫描（B1）

> 对应项目流程：给定参考基因组 → 枚举候选 gRNA → 特征化 → 初筛

## 1. 项目流程步骤
1. 下载 E. coli K-12 MG1655 参考基因组（NCBI RefSeq NC_000913）
2. PAM 扫描：SpCas9 NGG / Cas12a TTTV，全基因组枚举 20nt 候选
3. 靶基因注释：EcoCyc/RegulonDB 获取基因功能、通路、必需性
4. 特征工程：GC 含量、poly-T、种子区错配、位置特征、RNA 二级结构（ViennaRNA）
5. 同源位点扫描：与全基因组比对（mm ≤3）预估脱靶候选
6. 输出：候选 gRNA 表（含全部特征），供 M1/M2 评分

## 2. 文献支撑
| 文献 | 分级 | 支撑点 |
|---|---|---|
| CRISPOR (Haeussler 2016) | S | 位点扫描+评分管线参考实现 |
| DeepCRISPR | S | 特征编码方案（one-hot + 保守性特征） |
| EcoCyc / RegulonDB | S | 基因功能与调控注释（靶基因功能化） |
| CRISPRscan | S | 序列特征与体内效率的经验关系 |

## 3. 生信方法指导
- 工具：Biopython（基因组解析、回文/PAM 搜索）、pyfaidx（索引）、ViennaRNA（二级结构）、BLASTn/EMBOSS（同源扫描）
- 输入：FASTA 基因组 + GFF 注释 + 必需基因表（PEC）
- 输出：BED/CSV 候选表（chrom, pos, strand, sequence, PAM, gene, features）
- 参数：seed region 定义为 PAM 上游 8-12nt；脱靶容错 mm≤3
- 并行：全基因组扫描用 multiprocessing 或 pysam 分区

## 4. 大模型训练建议
- 候选排序可用 DNA 预训练模型 embedding（DNABERT-2）替代手工特征
- 特征融合：序列 embedding + 基因功能 embedding（如 GO term 编码）
- 模型可解释：SHAP 定位对效率贡献最大的序列位置

# 知识库 · 模块 06：多组学机制解析（B2）

> 对应项目流程：ALE 菌株/工程菌 → WGS/RNA-seq/代谢组 → 瓶颈识别 → 靶点线索

## 1. 项目流程步骤
1. WGS 变异解析：对课题 2 的 ALE 菌株（M8）重测序 → breseq 变异鉴定
2. 转录组：工程菌 vs 对照差异表达（DESeq2）→ GO/KEGG 富集
3. 代谢网络建模：iML1515 + FBA/pFBA → 通量分布与瓶颈节点
4. 交叉验证：突变基因 × 差异表达 × 通量瓶颈三者交集 → 关键靶点
5. 输出：带证据链的靶点优先级（基因 × 操作 × 置信度）

## 2. 文献支撑
| 文献 | 分级 | 支撑点 |
|---|---|---|
| iML1515 (Monk 2017) | S | E. coli 基因组规模代谢模型（FBA 基础） |
| DESeq2 (Love 2014) | S | 转录组差异分析标准方法 |
| breseq (Deatherage & Barrick 2014) | S | ALE 变异解析流程 |
| Omic data from evolved E. coli (2010) | A | 进化菌株多组学与 GEM 预测一致性验证 |

## 3. 生信方法指导
- WGS：FastQC → Trimmomatic → breseq（或 BWA+GATK）→ VCF 注释（SnpEff）
- RNA-seq：STAR/HISAT2 比对 → featureCounts → DESeq2 → clusterProfiler 富集
- FBA：cobrapy（python）+ iML1515.json；pFBA/parsimonious FBA；双敲除模拟（基因必需性分析）
- 代谢瓶颈：通量变异性分析（FVA）+ shadow price 分析定位限制性反应
- 输出标准：突变表（VCF→TSV）、差异表达表（log2FC+padj）、通量表（reaction, flux, bounds）

## 4. 大模型训练建议
- 多组学整合：将变异/表达/通量特征拼接为样本向量，训练基因-表型预测模型
- 因果推断：用 GEM 通量作中间变量做中介分析（突变→通量→产量）
- LLM 辅助：将差异表达+富集结果喂给 LLM（RAG），自动生成机制假说
- 主动学习：不确定性最高的基因优先做湿实验验证

# 知识库 · 模块 07：基因型-表型关联（B3）

> 对应项目流程：多菌株表型数据 → 关联分析 → 靶点优先级输出

## 1. 项目流程步骤
1. 收集多菌株（不同改造组合）的基因型与表型（滴度/得率）
2. 特征化：基因型 → 特征向量（基因存在/缺失、突变位点、gRNA 设计）
3. 关联建模：XGBoost / 逻辑回归 → SHAP 特征重要性
4. 分层建模：按前体供给/辅因子/调控等模块分层关联
5. 输出：基因-表型关联表 + 可解释性报告

## 2. 文献支撑
| 文献 | 分级 | 支撑点 |
|---|---|---|
| LLM for Metabolic Engineering (2024) | S | LLM 进行基因-表型推理与靶点推荐范式 |
| L-Homoserine strategies review (2024) | S | 靶点-产量关联的领域先验 |
| PEP-OAA-Pyruvate review (2024) | S | 前体供给节点的表型影响 |
| E. coli β-alanine multi-biosensor (2022) | S | 生物传感器辅助的基因型-表型筛选 |

## 3. 生信方法指导
- 工具：scikit-learn（XGBoost/逻辑回归）、SHAP、statsmodels
- 特征工程：基因二进制编码 + 连续表型标准化；gRNA 序列 embedding
- 统计：多重检验校正（BH-FDR）；分层交叉验证
- 注意：菌株数通常较少（<100），需强正则化 + 先验约束（GEM 约束）

## 4. 大模型训练建议
- 多模态：基因型文本 + 序列 embedding + 表型数值 → 多任务模型
- LLM 生成候选靶点 → 与统计关联结果交叉验证（人机协同）
- 不确定性量化：MC-dropout 或 ensemble，输出置信区间
