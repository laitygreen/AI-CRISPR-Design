## 依赖关系与并行策略

并行原则：数据(0) 完成后，生信(1) 与 模型(2) 并行推进；M3 依赖 1.4/1.5 结果作为训练语料；湿实验(3) 接收 1 与 2 的输出；数据回流再迭代模型。

## 关键风险与应对

| 风险 | 应对 |
|---|---|
| 里程碑 1 | 数据与基线就绪（P0） |
| 数据不足 | 公开数据集兜底（DeepCRISPR 2.8万 gRNA） |
| 算力不足 | LoRA 小模型 + 免费 Colab；LLM 用 API+RAG 模式 |
| 湿实验周期 | E1 先行（最快出结果）；E2 用现成课题平台 |
| 模型效果不佳 | 报告基线对比与消融，突出流程完整性与可复现 |
