## 一、项目定位与总体架构

### 1.1 项目一句话
> 构建一个“数据 → 生信解析 → 大模型设计 → CRISPR 湿实验验证 → 数据回流”的闭环系统，面向大肠杆菌 β-丙氨酸 / L-高丝氨酸细胞工厂，实现 gRNA 编辑效率预测、脱靶风险评估、代谢工程靶点智能推荐，并用湿实验数据闭环迭代模型，最终输出一套可复现、可解释、开源的 AI 基因编辑设计平台。

### 1.2 与上一版成稿的差异（升级点）
| 维度 | 上一版（可行性研究） | 本版（参赛实施方案） |
|---|---|---|
| 目标 | 一个月出原型 | 对标赛程：9/5 摘要、10/4 提交、10/16 决赛答辩 |
| 内容 | gRNA 效率预测 + 脱靶排序 + 表型弱关联 | 增加：大模型微调（LLM）、多组学生信解析、湿实验验证闭环、开源代码仓 |
| 交付 | 报告 + baseline | 评审表 + 项目介绍 + 原始代码 + 实验记录本 + 可复现仓库 |
| 亮点 | 传统 ML + 预训练底座 | LoRA 微调领域大模型 + Agent 化设计工作流 + 实验验证闭环（真验证） |

### 1.3 系统总体架构（五层）
```
展示层：Web 界面 / Notebook 报告 / 可视化（靶点热图、SHAP、通路图）
    ↑
应用层：CRISPR 靶点设计工作流（Agent）：给定产物 → 推荐基因靶点
        → 生成 gRNA 候选 → 效率/脱靶评分 → 排序 → 实验方案输出
    ↑
模型层（大模型训练核心）：
   M1 gRNA 编辑效率预测（DNA 预训练底座 + 微调）
   M2 脱靶/特异性预测（CNN/Transformer + 比对特征）
   M3 基因型-表型关联 / 代谢通路知识大模型（LLM 微调或 RAG）
    ↑
生信层：WGS 变异解析、转录组/代谢组、代谢网络建模(FBA/iML1515)、
        CRISPR 位点全基因组扫描、保守性/功能注释
    ↑
数据层：自产湿实验数据（gRNA/编辑/脱靶/表型）+ 公开数据
        （Doench/DeepCRISPR/GUIDE-seq/iML1515/EcoCyc/文献）
```
闭环：数据层 ↑ 湿实验验证（真验证）↓ 数据回流 → 模型迭代

## 二、模块 A：数据工程（真数据 —— 竞赛评审第一关）

### 2.1 数据字典（沿用成稿并扩展）
统一字段规范（CSV/JSON 双格式），全部带批次与元数据：
1. gRNA 设计字段：gRNA 序列、PAM、靶基因、靶位点坐标、Cas 类型（SpCas9/Cas12a）、编辑方式（敲除/敲入/CRISPRi）、载体、启动子、拷贝数、表达条件
2. 编辑结果字段：编辑是否成功、编辑效率（%）、indel 谱型、阳性克隆比例、测序验证方法（Sanger/amplicon-seq）
3. 脱靶字段：预测脱靶位点、实测脱靶位点、检测方法（WGS/GUIDE-seq/CIRCLE-seq）、脱靶频率、错配数
4. 构建背景字段：宿主菌株、出发株、改造历史、培养基、温度、pH、溶氧、诱导条件
5. 表型字段：目标产物滴度、得率、生产强度、生长速率、底物消耗、副产物、发酵时间点

### 2.2 公开数据源（可立即获取，用于预训练与基线）
| 数据 | 来源 | 用途 |
|---|---|---|
| gRNA 效率 | Doench 2016/2014 数据集、DeepCRISPR、CRISPRscan、Azimuth | M1 训练/评测 |
| 脱靶数据 | GUIDE-seq、CIRCLE-seq 公开数据集、CRISPR-Net 训练集 | M2 训练/评测 |
| 大肠杆菌基因组 | EcoCyc、NCBI RefSeq (MG1655) | 靶点扫描、注释 |
| 代谢网络模型 | iML1515 (GEM) | FBA 通量分析、靶点优先级 |
| 调控网络 | RegulonDB | 转录调控约束 |
| 领域文献/知识 | PubMed、BioCyc、蛋白结构 (AlphaFold) | LLM 微调/RAG |
| 蛋白/Cas 结构 | PDB、AlphaFold DB（SpCas9、Cas12a 变体） | 结构特征（可选加分项） |

### 2.3 数据管理规范（对应“最佳开源共享奖”）
- 仓库结构：data/raw、data/processed、data/splits（按宿主/批次划分，防泄漏）
- 每条记录保留 source（公开/自产）、experiment_id、lab_notes_ref 字段
- 负样本定义需在 README 中明确（“未编辑成功” ≠ 真负样本，需说明判定标准）
- 版本控制：DVC 或 git-lfs 管理数据版本

## 三、模块 B：生信分析（真问题 —— 支撑机制解释与靶点推荐）

### B1 CRISPR 位点全基因组扫描管线（对 E. coli MG1655）
1. PAM 搜索（NGG / Cas12a TTTV）→ 候选 gRNA 全基因组枚举
2. 特征工程：GC 含量、poly-T/U 结构、错配数、种子区（seed region）错配、位置特征、RNA 二级结构
3. 靶基因功能注释：KEGG/EcoCyc 通路、必需基因（PEC 数据库）、基因长度/启动子结构
4. 保守性与同源位点扫描（脱靶风险评估，mm ≤3）

### B2 多组学机制解析（与课题 2/3 的 ALE、动态调控数据对接）
- WGS 变异解析：对适应性进化（ALE）菌株做重测序 → SNV/InDel 鉴定（breseq/SNP-calling）→ 突变-表型关联 → 定位关键突变基因（如课题 2 的 ALE 菌株 M8）
- 转录组解析：差异表达基因（DESeq2/edgeR）→ GO/KEGG 富集 → 与产量变化关联 → 识别瓶颈节点
- 代谢网络建模：iML1515 + FBA/pFBA，计算关键通量（草酰乙酸供给、NADPH/NADH 平衡、PEP/丙酮酸节点）→ 找出碳流竞争位点 → 这些位点即 CRISPR 敲除/过表达候选靶点
- 输出：靶点优先级列表（基因 × 操作类型 × 置信度 × 证据链）

### B3 基因型-表型关联（可解释性）
- 传统：XGBoost/逻辑回归特征重要性 + SHAP
- 进阶：将 gRNA 序列 embedding + 基因功能 embedding 联合建模，输出“哪些基因扰动最可能提升 β-丙氨酸/L-高丝氨酸产量”

## 四、模块 C：大模型训练（AI 核心 —— 赛道二评审重点）

### C1 模型体系与训练策略
| 模型 | 任务 | 底座 | 训练方式 | 评估指标 |
|---|---|---|---|---|
| M1 gRNA 效率预测 | 回归/分类（高/低效） | DNA 预训练模型（DNABERT-2、Nucleotide Transformer、HyenaDNA）或 one-hot CNN baseline | 底座冻结/微调 + 监督头（LoRA 轻量微调） | Pearson r、Spearman ρ、AUROC、top-k 命中率 |
| M2 脱靶风险预测 | 二分类（脱靶/非脱靶） | CNN + 比对特征（CFD/DeepCRISPR 特征） | 监督微调 | AUROC、AUPR、top-k 召回 |
| M3 基因型-表型大模型 | 生成/排序：产物 → 推荐靶点组合 | 领域大模型（BioGPT / BioT5 / 通用 LLM + RAG + LoRA 微调） | LoRA 微调 + 检索增强（RAG） | 推荐命中率（湿实验验证）、BLEU/人工评估、消融 |
| M4 靶点设计 Agent | 端到端工作流 | M1+M2+M3 编排 + 规则引擎 | 无需额外训练，Prompt 编排 | 端到端湿实验命中率 |

**基线先行**（与成稿一致，但明确评测）：规则评分（CFD/MIT 评分、GC 规则）→ 传统 ML（XGBoost）→ 预训练底座微调 → 大模型。必须有基线对比，这是评审“科学性”的关键。

### C2 大模型微调（LLM）设计要点
1. 底座选择：优先考虑显存与算力——建议 BioT5（分子/生物序列到文本，多模态）或 BioGPT；若资源受限，退化为“通用 LLM（如 Qwen/Llama）+ RAG + LoRA”，同样算大模型应用
2. 微调语料（自建指令数据集）：
   - 指令：“请设计 3 条针对 E. coli panD 基因的高效敲除 gRNA” → 答案来自公开数据/专家标注
   - 指令：“β-丙氨酸合成前体供给不足，应优先改造哪些基因？” → 答案来自文献 + iML1515 分析
   - 指令：“给出该 gRNA 的脱靶风险评估理由” → 规则引擎 + 人工审核
3. LoRA 微调（显存友好）＋ 可解释输出（列出依据文献/数据）
4. 评估：留出测试集（按基因/宿主划分，防止同源泄漏），报告消融实验（有无 LLM 对推荐准确率的影响）

### C3 可解释性（对应“最佳机制解释奖”）
- M1/M2：SHAP 值、序列位置注意力热图、motif 分析
- M3：检索来源引用、证据链展示（“为什么推荐 sthA 敲除”→ 显示 NADPH 平衡数据）

## 五、模块 D：湿实验验证（真验证 —— 竞赛最强调的亮点）

### D1 验证闭环设计（核心叙事：“AI 设计 → 实验验证 → 数据回流”）
```
第1轮：模型在公开数据训练 → 对 E. coli 全基因组推荐 20~30 个 gRNA/靶点
  ↓
湿实验：CRISPR-Cas9/Cas12a 编辑（敲除/过表达/CRISPRi），Sanger/amplicon 测序确认
  ↓
实测：编辑效率、脱靶（amplicon-seq / 简化 WGS）、摇瓶/发酵 β-丙氨酸或 L-高丝氨酸滴度
  ↓
数据回流：实测数据加入训练集 → 第2轮模型迭代 → 展示模型准确率提升曲线
  ↓
第2轮：微调后模型重新推荐 → 湿实验复验 → 形成“模型-实验共进化”证据
```

### D2 具体实验方案（与三个课题衔接）
| 实验 | 内容 | 对接课题 |
|---|---|---|
| E1 gRNA 效率回构 | 选 3 个基因 × 每基因 5 条 gRNA（覆盖预测高/中/低），CRISPR 编辑，测序验证 | 课题 1/2/3 共用的编辑平台 |
| E2 靶点组合改造 | 按 M3 推荐组合改造：如强化 panD/aspC 前体模块、敲除竞争基因、改造 NADPH 再生（GapN/AspDH） | 课题 1（β-丙氨酸主线）、课题 2（辅因子/ALE 模块） |
| E3 动态调控验证（可选） | 群体感应动态调控元件（Lsr 系统）构建与验证 | 课题 3（L-高丝氨酸） |
| E4 模型迭代复验 | 第 2 轮推荐位点复验，量化模型增益 | 全部 |

### D3 实验记录规范（总决赛备查）
- 每轮实验建独立目录：experiments/EXP-XX/（设计表、原始数据、分析脚本、结论）
- 电子实验记录本（Markdown + 时间戳）+ 关键原始文件（测序峰图/FASTQ 摘要）留存
