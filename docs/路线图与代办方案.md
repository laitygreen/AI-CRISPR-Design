## [3] 数据统一处理与清洗（质量决定模型上限）

### 流程
    原始数据 → 字段映射(统一字典) → 去重 → 缺失标记 → 负样本定义 → 划分(防泄漏) → DVC版本

### 关键规则（来自文献卡）
    - 防泄漏: 按基因/宿主分组划分，避免同源 gRNA 同时进训练与测试
    - 去冗余: 序列 Hamming≤8 的候选合并
    - 负样本: 脱靶负样本按错配数 4-8 采样；效率负样本需测序证据
    - 类别平衡: 脱靶正负比可达 1:250，需 bootstrapping/加权损失
    - 尺度归一: 效率标签 rank 归一化（跨实验整合）

## [4] 模型训练方法（代码已就绪，待真实数据）

### 四模型 + 一分析路线
| 模块 | 方法 | 代码 | 真实数据接入点 |
|---|---|---|---|
| M1 效率 | 多尺度 CNN（3/5/7）+ one-hot 30mer | src/aicrispr/grna_efficiency/ | 2.1 → 换 CSV |
| M2 脱靶 | CNN(序列)+MLP(错配)双路 | src/aicrispr/offtarget/ | 2.2 → 换 CSV |
| C 底座 | DNABERT-2 嵌入（降级 k-mer） | src/aicrispr/embeddings/ | 网络可达时拉权重 |
| D LLM/Agent | RAG-lite 靶点推荐 + Agent | src/aicrispr/llm_agent/ | 扩知识库 |
| E FBA | cobrapy + iML1515 | src/aicrispr/gem/ | 已验证可用 |

### 训练协议要点
    - 基线先行: 规则(CFD) → XGBoost → CNN → 预训练底座微调（必须有对比）
    - 评估: Pearson/Spearman（M1）、AUROC/AUPR（M2）、top-k 命中率
    - 防过拟合: Dropout + 正则 + 集成；小样本用主动学习
