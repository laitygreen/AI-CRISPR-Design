## 项目名称
**AI-CRISPR 驱动的代谢工程菌株智能设计系统：面向大肠杆菌氨基酸细胞工厂的编辑效率预测、脱靶评估与靶点智能推荐**

## 项目摘要

CRISPR 基因编辑已成为微生物细胞工厂构建的核心工具，但 gRNA 设计高度依赖经验试错，编辑效率与脱靶风险预测不准、代谢工程靶点组合缺乏系统推荐，严重制约菌株改造周期。本项目面向大肠杆菌 β-丙氨酸 / L-高丝氨酸生物合成体系，构建一套“生信解析—大模型设计—湿实验验证—数据回流”闭环的 AI 基因编辑设计系统。

系统包含四个核心模型：(1) 基于 DNA 预训练模型（DNABERT-2 / Nucleotide Transformer）微调的 gRNA 编辑效率预测模型，对大肠杆菌全基因组位点打分排序；(2) 融合比对特征与深度网络的脱靶风险预测模型，实现特异性评估；(3) 经 LoRA 微调的领域大语言模型（BioGPT/BioT5 路线），结合检索增强，实现“给定目标产物→推荐代谢靶点组合与编辑策略”的生成式设计；(4) 靶点设计 Agent 将上述模型编排为端到端工作流。

生信层面，我们整合 WGS 变异解析（ALE 进化菌株）、转录组分析与 iML1515 代谢网络通量模拟，识别前体供给、辅因子平衡等瓶颈节点，为模型推荐提供机制解释与证据链。湿实验层面，在 E. coli 中开展 CRISPR-Cas9/Cas12a 编辑回构验证，实测编辑效率与目标产物滴度，并将数据回流迭代模型，形成“模型-实验共进化”证据。

项目产出可复现、可解释、开源的 CRISPR 设计平台及完整代码仓库，直接服务 β-丙氨酸、L-高丝氨酸等氨基酸生物制造，具有明确产业转化前景。
