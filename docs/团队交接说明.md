## 一、项目是什么

**AI-CRISPR 驱动的代谢工程菌株智能设计系统** —— 第一届全球大学生生命科学挑战赛·赛道二（AI 基因编辑与核酸工具设计）参赛项目。

用 AI 预测 CRISPR gRNA 编辑效率与脱靶风险，并智能推荐大肠杆菌氨基酸细胞工厂（β-丙氨酸 / L-高丝氨酸）的代谢工程靶点。

**六模块功能**：
| 模块 | 功能 | 对应比赛模块 |
|---|---|---|
| crispr_scan | 全基因组 PAM 扫描 + gRNA 枚举 | B1 |
| grna_efficiency | gRNA 编辑效率预测 | M1 |
| offtarget | 脱靶风险评估 | M2 |
| embeddings | DNA 序列嵌入提取 | M1 特征 |
| llm_agent | 靶点推荐 + RAG 知识库 | M3/M4 |
| gem | 代谢网络 FBA 分析 | B2 |

## 二、环境搭建（迁移说明）

### 必备环境
1. **Python 3.10**（3.13 已弃用：其 site-packages 被旧包污染，扩展模块报错；脚本内置版本守卫会自动拦截）
2. 依赖：`pip install -e .`（自动装 torch/numpy/pandas/scipy/sklearn/biopython/transformers/cobra 等）

### 快速验证
```bash
cd AI-CRISPR-Design
python demo_routes.py        # 一键验证五路线
# 或按路线跑：
python routes/route01_gRNA效率/routeA_train.py --train data.csv --out out/
```

### 常见问题
| 问题 | 解决 |
|---|---|
| ModuleNotFoundError: torch | 用 Python 3.10 而非 3.13 |
| huggingface 连接失败 | 自动降级 k-mer 模式（离线可用） |
| cobra 加载 iML1515 失败 | 先下载 iML1515.json 用 --model 指定 |
| git push SSL 失败 | `git config http.sslBackend openssl` |
